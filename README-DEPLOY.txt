HOMEKEEP GUIDE — VERCEL DEPLOY

1. Extract all files into one project root.
2. Replace the placeholder Contact text in index.html with a real monitored email before AdSense review.
3. Deploy the folder to Vercel.
4. After you know the final Vercel domain, add a canonical URL and Sitemap line to robots.txt, then create sitemap.xml for that exact domain.
5. Verify /ads.txt displays exactly:
   google.com, pub-5129712797856897, DIRECT, f08c47fec0942fa0
6. Add the final site URL in AdSense only when the site is complete and publicly accessible.

AdSense approval is determined by Google and cannot be guaranteed.
